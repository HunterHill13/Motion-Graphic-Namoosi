### 1.3 Visual Bridges & Match Cuts (Spatial Continuity)

Premier studios reject hard cuts between scenes. Hard cuts destroy the viewer's mental model of the space. Instead, they use **4 Physical Continuity Bridges**:

#### 1. Momentum Handoff (Kinetic Vector Conservation)
An exiting element's exit velocity vector $\vec{v}_{\text{exit}}$ directly drives the entry velocity vector $\vec{v}_{\text{entry}}$ of the incoming element:
$$\vec{v}_{\text{entry}}(t_0) = \alpha \cdot \vec{v}_{\text{exit}}(t_{\text{cut}}), \quad \alpha \in [0.85, 1.15]$$
*Example:* A data card whips off the left edge at $1800\text{ px/s}$. In the exact frame it clears the edge, a new topographic map rushes in from the right edge at the identical velocity, decelerating with a shared damping coefficient. The eye perceives a continuous transfer of kinetic momentum.

#### 2. Topological Morph (Volume & Mass Conservation)
An entity changes its semantic identity while **conserving total mass, surface area, and center of gravity**:
$$\oint_{\partial \Omega_A} d\mathbf{r} \approx \oint_{\partial \Omega_B} d\mathbf{r}, \quad \mathbf{C}_A \approx \mathbf{C}_B$$
*Example:* In an Apple Keynote or Ordinary Folk piece, an iPhone silhouette rotates 90 degrees, its rounded corners expand into a sleek aluminum laptop base, while the camera notch morphs into the trackpad. The bounding footprint remains anchored in the viewer's foveal center.

#### 3. Spatial Zoom-Through (Micro/Macro Aperture Penetration)
The camera accelerates along the Z-axis, penetrating an aperture within an object in Scene A, and exits into the vast coordinate space of Scene B:
$$Z_{\text{camera}}(t) = Z_0 + \Delta Z \cdot \left( \frac{t}{D} \right)^3$$
*Example:* In Kurzgesagt, the camera zooms into the black pupil of a human eye. As the pupil expands beyond the viewport edges, its pure blackness becomes the vacuum of deep interstellar space, revealing galaxies rotating into view.

#### 4. Graphic Match Cut (Silhouette & Chroma Seam)
Matching geometric silhouettes, negative space contours, or color fields across the transition boundary:
*Example:* A circular pie chart in Act 1 matches the circular aperture lens of a cryo-microscope in Act 2, which matches the circular verification stamp in Act 4.

### 1.4 Hierarchy of Motion (The 70-20-10 Rule)

At any given frame, the viewer's eye can only track **ONE dominant motion vector**. If multiple elements move independently with equal visual weight, visual chaos ensues.

```text
┌──────────────────────────────────────────────────────────┐
│                   TERTIARY (10% WEIGHT)                  │
│       Ambient living noise, subtle filmic dither,        │
│       breathing coordinate grid, depth-of-field drift    │
│                                                          │
│     ┌──────────────────────────────────────────────┐     │
│     │            SECONDARY (20% WEIGHT)            │     │
│     │    Callout leader lines, reactive metric     │     │
│     │    counters, lagged badges, inertial ripple  │     │
│     │                                              │     │
│     │   ┌──────────────────────────────────────┐   │     │
│     │   │         PRIMARY (70% WEIGHT)         │   │     │
│     │   │       Narrative Hero Actor           │   │     │
│     │   │  (Carries the core semantic thesis;  │   │     │
│     │   │   explodes, transforms, or docks)    │   │     │
│     │   └──────────────────────────────────────┘   │     │
│     └──────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────────┘
```

1. **Primary Motion (70% Visual Weight):**
   - The central narrative actor (the hero diagram, the monumental phrase, or the transforming apparatus).
   - Only ONE primary action is active at any single moment.
2. **Secondary Motion (20% Visual Weight):**
   - Reactive elements that move **only because the primary actor moved**.
   - If the hero card slams down, the metric badge bounces 4 frames later with critically damped inertial lag. If the hero expands, leader lines sprout outward from its boundary.
3. **Tertiary Motion (10% Visual Weight):**
   - Ambient, non-distracting environmental life.
   - 3.5% filmic dither, subtle floating dust motes, breathing coordinates, gentle 0.02Hz camera hover.
   - Prevents the frame from ever freezing ("alive canvas"), but never competes with primary or secondary motion.

```typescript
export function computePhysicalCraneAndShutter(
  frame: number,
  trajectoryFn: (f: number) => { x: number; y: number; z: number }
) {
  const dt = 0.5;
  const p0 = trajectoryFn(frame - dt);
  const p1 = trajectoryFn(frame);
  const p2 = trajectoryFn(frame + dt);

  const vx = (p2.x - p0.x) / (2 * dt);
  const vy = (p2.y - p0.y) / (2 * dt);
  const ax = (p2.x - 2 * p1.x + p0.x) / (dt * dt);
  const ay = (p2.y - 2 * p1.y + p0.y) / (dt * dt);

  const camRoll = Number((-ax * 0.045).toFixed(2));
  const camPitch = Number((ay * 0.035).toFixed(2));
  const speed = Math.sqrt(vx * vx + vy * vy);

  // Directional motion blur vector
  const blurAngleRad = Math.atan2(vy, vx);
  const blurLength = Math.min(16, speed * 0.12);

  return {
    camX: p1.x,
    camY: p1.y,
    camZ: p1.z,
    camRoll,
    camPitch,
    blurLength,
    blurAngleDeg: (blurAngleRad * 180) / Math.PI,
  };
}
```
